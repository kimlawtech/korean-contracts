# 스킬 테스트 사례 모음

각 스킬을 검증하기 위한 테스트 케이스.
아래 입력값을 Claude Code에서 해당 슬래시 명령어로 실행해 결과를 확인한다.

---

## 사용법

```
/employment-contract
→ 인터뷰 시작 후 아래 케이스 데이터를 순서대로 입력
```

또는 케이스 전체를 한 번에 붙여넣어도 된다.

---

## 1. `/employment-contract` — 근로계약서

### CASE 1-A: 정규직 (기본 케이스)
**시나리오**: 스타트업 마케터 정규직 채용. 5인 이상, 수습 3개월.

```
기존 계약서: 없음

사업자: 주식회사 모카 / 대표 홍길동 / 서울 강남구 테헤란로 123 / 123-45-67890
근로자: 이직원 / 950101 / 서울 서초구 / 010-1234-5678
직무: 마케터 / SNS 콘텐츠 기획·운영, Instagram·블로그 관리
근무지: 서울 강남구 본사
고용형태: 정규직
근무: 주 5일(월~금), 09:00~18:00, 점심 12:00~13:00
임금: 기본급 2,700,000 + 식대 200,000 + 교통비 100,000 = 3,000,000원
지급일: 매월 25일
4대보험: 전부
수습: 3개월, 수습급여 2,700,000원
연차: 15일
추가조항: 비밀유지, 겸업금지, 지식재산권
규모: 5인 이상
저장: ~/Desktop
```

**검증 포인트**
- [ ] §17 필수 5항목 포함
- [ ] 수습 90% 감액 (2,700,000 / 3,000,000 = 90%) 적용 확인
- [ ] 최저임금: 3,000,000 / 209 = 14,354원 → 통과
- [ ] 5인 이상 가산수당·연차 조항 포함

---

### CASE 1-B: 계약직 + 고정OT (엣지 케이스)
**시나리오**: 1년 계약직 개발자. 포괄임금, 고정OT 월 20시간. 5인 이상.

```
기존 계약서: 없음

사업자: 주식회사 테크랩 / 대표 김대표 / 서울 마포구 월드컵북로 400 / 234-56-78901
근로자: 박개발 / 920315 / 경기 성남시 / 010-9876-5432
직무: 백엔드 개발자 / Node.js 서버 개발, API 설계 및 유지보수
근무지: 서울 마포구 본사
고용형태: 계약직 / 2026-05-01 ~ 2027-04-30 (1년)
근무: 주 5일, 10:00~19:00, 점심 13:00~14:00
임금: 기본급 3,500,000 + 식대 200,000 + 고정연장수당 400,000 = 4,100,000원
  (고정OT: 월 20시간)
지급일: 매월 10일
4대보험: 전부
수습: 없음
연차: 11일 (1년 미만)
추가조항: 비밀유지, 지식재산권
규모: 5인 이상
저장: ~/Desktop
```

**검증 포인트**
- [ ] 갱신기대권 방지 문구 자동 삽입
- [ ] 기본급 시급 단독 검증: 3,500,000 / 209 = 16,746원 → 통과
- [ ] 고정OT 시간·금액 명시 확인
- [ ] 포괄임금 최저임금 미달 무효 조항 (대법원 2024.12.26.) 반영 확인
- [ ] 계약 2년 초과 아님 → 경고 없어야 함

### CASE 1-C: 기존 계약서 검토 (개정법령 반영 테스트)
**시나리오**: 2024년에 작성한 근로계약서. 최저임금 미달 + 구법 항목 다수.

```
기존 계약서 내용:

근 로 계 약 서

주식회사 올드컴퍼니(이하 "사용자")와 최직원(이하 "근로자")은 다음과 같이 근로계약을 체결한다.

제1조 (계약기간) 2024년 3월 1일부터 기간의 정함이 없이 근무한다.
제2조 (근무장소 및 업무) 근무장소: 서울 중구 세종대로 110. 업무: 영업 및 기타 필요한 업무.
제3조 (근로시간) 09:00~18:00, 휴게 12:00~13:00, 주 5일 근무.
제4조 (임금) 월 급여 2,090,000원. 지급일: 매월 25일.
제5조 (연차) 1년 만근 시 15일.
제6조 (배우자 출산휴가) 배우자 출산 시 유급휴가 10일.
제7조 (퇴직금) 1년 이상 근무 시 퇴직 시 일시 지급.
제8조 (해고) 30일 전 예고 또는 30일분 임금 지급.

2024년 2월 25일
사용자: 주식회사 올드컴퍼니 홍길동 (인)
근로자: 최직원 (인)
```

**검증 포인트**
- [ ] ❌ 최저임금 미달: 2,090,000 / 209 = 9,999원 < 10,320원
- [ ] ❌ 배우자 출산휴가 10일 → 20일로 수정 권고
- [ ] ⚠️ 임금명세서 교부 조항 없음
- [ ] ⚠️ 통상임금 재직조건부 상여금 조항 없음
- [ ] 💡 업무내용 "기타 필요한 업무" 포괄 기재 → 구체화 권고
- [ ] 💡 임금 구성 항목 미분리 → 분리 권고
- [ ] 수정 항목 선택 → 재작성 흐름 확인

## 2. `/parttime-contract` — 알바·단시간 계약서

### CASE 2-A: 주 15시간 이상 (주휴수당 발생)
**시나리오**: 카페 파트타임. 주 4일 × 5시간 = 주 20시간. 5인 미만.

```
기존 계약서: 없음

업종: 카페
상호: 홍카페
규모: 5인 미만
사업주: 홍사장 / 010-1111-2222

근로자: 김알바 / 030505 / 010-3333-4444

근무 요일: 월·화·목·금
근무 시간: 09:00~14:00 (5시간)
휴게: 11:30~12:00 (30분)

시급: 11,000원
지급일: 매월 25일

계약기간: 2026-05-01 ~ 2026-10-31

저장: ~/Desktop
```

**검증 포인트**
- [ ] 주 소정근로시간: 4일 × 5시간 = 20시간 → 15시간 이상
- [ ] 주휴수당 자동 계산: (20/40) × 8 × 11,000 = 44,000원/주
- [ ] 요일별 근로시간 테이블 자동 생성 (기간제법 §17②)
- [ ] 4대보험 전부 가입 안내
- [ ] 5인 미만 → 가산수당 의무 없음 확인

---

### CASE 2-B: 주 15시간 미만 (주휴수당 미발생)
**시나리오**: 편의점 초단시간. 주 3일 × 4시간 = 주 12시간.

```

업종: 편의점
상호: GS25 홍대점
규모: 5인 미만
사업주: 이편의 / 010-5555-6666

근로자: 박초단 / 050101 / 010-7777-8888

근무 요일: 화·목·토
근무 시간: 22:00~02:00 (4시간)
휴게: 없음 (4시간 미만 해당 없음)

시급: 10,500원
지급일: 매주 월요일

계약기간: 2026-05-01 ~ 2026-07-31

저장: ~/Desktop
```

**검증 포인트**
- [ ] 주 12시간 → 15시간 미만 분기 확인
- [ ] 주휴수당 미발생 명시
- [ ] 연차 미발생 명시
- [ ] 4대보험: 산재보험만 의무 안내
- [ ] 야간근로(22:00~06:00): 5인 미만 → 가산수당 의무 없음
- [ ] 시급 10,500원 > 10,320원 → 통과

**시나리오**: IT 스타트업 디자이너. 코어타임 있는 선택근로제. 5인 이상.

```
기존 계약서: 없음

사업자: 주식회사 플렉스 / 대표 유연대 / 서울 성수동 / 345-67-89012
근로자: 정디자인 / 910202 / 서울 광진구 / 010-2345-6789
직무: UX/UI 디자이너 / 앱·웹 화면 설계, 사용자 리서치
근무지: 서울 성수동 사무실 + 재택 병행

유연근무 유형: 선택적 근로시간제
코어타임: 10:00~15:00
정산 기간: 1개월
월 총 소정근로시간: 209시간
취업규칙: 있음 (선택근로 조항 포함)

규모: 5인 이상
추가: 비밀유지, 지식재산권
```

- [ ] 선택근로 취업규칙 + 서면합의 이중 요건 안내 확인

- [ ] 정산 기간 말 초과근로 처리 방침 조항 포함 확인
- [ ] 서면합의서 별도 작성 안내 출력 확인

## 4. `/freelancer-contract` — 프리랜서 계약서

### CASE 4-A: 디자인 프로젝트 (기본 케이스)
**시나리오**: 모바일 앱 UI 디자인 외주. 착수금 30% + 잔금 70%.

```
기존 계약서: 없음

발주자: 주식회사 앱메이커 / 대표 앱대표 / 서울 강남구 / 567-89-01234 / 담당 김앱
수급자(프리랜서): 이디자인 / 940303 / 010-4567-8901 / 개인 (사업자등록 없음)

업무: 모바일 앱 UI 디자인
상세: iOS·Android 앱 전체 화면 30개, Figma 파일 납품
결과물: Figma 소스 파일, PNG 에셋, 디자인 가이드 PDF

계약금액: 4,500,000원 (원천징수 3.3% 적용)
지급: 착수금 1,350,000원 (계약 시) + 잔금 3,150,000원 (최종 납품 후 7일 이내)

기간: 2026-05-01 ~ 2026-06-30
납기: 2026-06-30

지식재산권: 발주자 소유 (잔금 완납 후 이전)
수정: 3회 이내 무상, 초과 시 회당 200,000원
비밀유지: 있음
재하도급: 금지

저장: ~/Desktop
```

**검증 포인트**
- [ ] 원천징수 자동 계산: 4,500,000 × 3.3% = 148,500원 → 실지급 4,351,500원
- [ ] 착수금 지급 시 원천징수: 1,350,000 × 3.3% = 44,550원
- [ ] 잔금 완납 전 저작권 이전 거부 가능 조항 확인
- [ ] 수정 횟수 3회 + 추가 단가 명시 확인
- [ ] 위장 프리랜서 7대 요소 → 해당 없음 확인

### CASE 4-B: 위장 프리랜서 경고 테스트
**시나리오**: 겉으로는 프리랜서지만 실질 근로자 요소 다수.

```
기존 계약서: 없음

발주자: 주식회사 위험컴퍼니 / 대표 위험대표 / 서울 마포구
수급자: 강위험 / 001212

업무: 마케팅 업무 전반 및 기타 회사가 지시하는 모든 업무
계약금액: 월 2,500,000원 (3.3% 원천징수)
기간: 2026-05-01 ~ 2026-10-31 (6개월)
근무: 매일 09:00~18:00 회사 사무실 출근 의무
장비: 회사 제공 PC·소프트웨어만 사용
```

**검증 포인트**

  - 매일 09:00~18:00 출근 (요소 2)
  - 회사 장비 전속 사용 (요소 4)
  - 월정액 고정 지급 (요소 5)
  - 겸업 전면 금지 (요소 3)
  - 대표이사 직접 지시 (요소 1)
- [ ] 계약서 생성 전 근로계약으로 전환 권고 출력 확인

## 5. `/outsourcing-contract` — 외주용역계약서

### CASE 5-A: 웹사이트 개발 발주 (기본 케이스)
**시나리오**: 쇼핑몰 웹사이트 개발. 하도급법 §3 필수 7항목 포함.

```
기존 계약서: 없음

발주사: 주식회사 쇼핑왕 / 대표 쇼핑대표 / 서울 강남구 / 678-90-12345 / 담당 박쇼핑
수주사: 주식회사 개발왕 / 대표 개발대표 / 서울 종로구 / 789-01-23456 / 담당 이개발

용역명: 쇼핑몰 웹사이트 개발
범위: 회원가입·상품 등록·장바구니·결제(PG 연동)·배송 추적 기능
제외: 서버 운영 비용, 제3자 API 비용 (PG사·배송사)
산출물: 소스코드, AWS 배포 서버, 운영 매뉴얼

계약금액: 50,000,000원 (VAT 별도)
지급: 착수금 15,000,000원 + 중도금 20,000,000원 (개발완료 시) + 잔금 15,000,000원 (검수 후)

기간: 2026-05-01 ~ 2026-09-30
납기: 2026-09-15 (개발 완료)
```
