## 핵심 법리 (일용근로자 특유)

### 일용근로자 정의

```
근로기준법 §2: "1일 단위로 근로계약을 체결하고 그 날의 근로가 끝나면
고용관계가 종료되는 근로자"

실무 기준:
- 동일 사업장에서 1개월 미만 고용 → 일용근로자
- 1개월 이상 계속 근무 시 → 월급 근로자로 전환 간주 (4대보험 의무)
- 건설업 특례: 고용 일수 관계없이 건설 일용직 취급 가능 (고용보험법)
```

### 4대보험 가입 기준 (일용직)

```
산재보험:  모든 일용직 → 의무 가입 (1일이라도)
고용보험:  
  - 1개월 미만 또는 월 60시간 미만 → 해당 없음
  - 단, 3개월 이상 계속 고용 → 가입 의무 발생
  - 건설 일용직 → 별도 고용보험 특례 적용
국민연금·건강보험:
  - 1개월 미만 일용직 → 해당 없음
  - 1개월 이상·월 60시간 이상 → 의무 가입
```

### 일용근로소득세 원천징수

```
일용근로자 원천징수 (소득세법 §129):
  과세 일당 = 일당 - 150,000원 (비과세 한도)
  산출세액 = 과세 일당 × 6% (기본세율)
  원천징수세 = 산출세액 × 55% (근로소득세액공제 45%)
  최종 세율 ≈ 2.7% (일당의)

지방소득세 = 원천징수세 × 10%

예시: 일당 200,000원
  → 과세 일당 50,000원 × 6% × 55% = 1,650원 (소득세)
  → 지방소득세 165원
  → 실 수령액 = 200,000 - 1,815원 ≈ 198,185원

일당 150,000원 이하는 원천징수 없음
```

### 일용직 주휴수당

```
1일 단위 계약 → 주휴수당 미발생 (고용관계 1일로 종료)
단, 동일 사업장에서 주 15시간 이상·1주 이상 계속 근무 시
→ 주휴수당 발생 가능성 (법원 판례 주의)
→ 실질적 상용직 전환 가능성 안내 필요
```

## 동작 순서

### 1단계: 업종 및 근무 형태 확인

```
① 업종 선택
  - 건설 일용직
  - 행사·전시 스태프
  - 배달·물류
  - 일반 단기 아르바이트
  - 기타

② 근무 일정
  - 단 1일 / 2~7일 / 1주 이상
  - 특정일(들) 지정 or 기간 내 탄력 근무
```

### 2단계: 기본 정보 수집

```
사용자:
- 사업자명 / 현장명 (건설의 경우)
- 대표자 / 현장소장
- 사업자번호
- 주소·연락처

근로자:
- 성명
- 주민등록번호 앞 6자리
- 주소·연락처
```

### 3단계: 근무 조건 수집

```
· 근무 일자 (구체적 날짜 또는 기간)
· 근무 시간대 (시작~종료)
· 휴게 시간 (4시간 이상 근무 시 30분 이상 필수)
· 근무 장소
· 담당 업무
```

### 4단계: 임금 수집 및 최저임금 검증

```
임금 형태 선택:
  ① 시급제 — 시급 × 근무시간
  ② 일당제 — 일당 고정
  ③ 혼합제 — 기본 일당 + 건당 인센티브

최저임금 검증:
  시급제: 시급 ≥ 10,320원
  일당제: 일당 ÷ 근무시간 ≥ 10,320원
  → 미달 시 경고 출력, 생성 금지

원천징수 계산 (자동):
  일당 > 150,000원 시 소득세 2.7% + 지방소득세 0.27% 공제 안내
```

### 5단계: 4대보험 판단

```
계약 기간·고용 일수 기반으로 자동 판단:
  - 산재보험: 항상 "의무 가입" 표기
  - 고용보험: 계약 형태에 따라 해당/해당없음 분기
  - 국민연금·건강보험: 1개월 미만이면 "해당 없음"
  
1개월 이상 계속 고용 예정 시 경고:
  "1개월 이상 계속 고용 시 4대보험 전환 의무가 발생합니다."
```
