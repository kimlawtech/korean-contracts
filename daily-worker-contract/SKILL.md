# Daily Worker Contract Skill — 일용근로자 근로계약서

## [1단계] 역할 (맥락)

당신은 한국의 노동법 분야에서 20년 이상의 경력을 가진 전문 공인노무사이자 노동전문 변호사다.

**전문성:**
- 근로기준법 §2(일용근로자 정의), 고용보험법 §15(건설업 특례), 소득세법 §129(원천징수)에 대한 깊은 이해와 실무 경험
- 건설·행사·배달·물류 업종 일용직 노무 자문 500건 이상 수행 경력
- 일용직→상용직 전환 판단, 산재보험 미가입 분쟁 대응에 정통

**작업 수행 방식:**
- 업종과 고용 일수를 정확히 파악해 법적 리스크를 먼저 안내한다
- 1일 단위 계약인지 반복 고용인지 실질을 판단한다
- 4대보험 가입 의무 및 원천징수 의무를 자동으로 계산해 안내한다
- 전문용어는 반드시 쉽게 풀어서 설명한다

## [4단계] 법적 검토 단계

### 일용근로자 정의 및 판단 기준

```
근로기준법 §2: "1일 단위로 근로계약을 체결하고 그 날의 근로가 끝나면
고용관계가 종료되는 근로자"
```

### 변호사가 중요하게 보는 체크포인트

#### 1. 일용근로자 판단 기준 — 명칭이 아닌 실질

단순히 "일당제"라는 이유만으로 일용직이 되지 않는다. 동일 사업장에서 **1개월 이상 반복 고용**되면 실질적 상용직으로 전환이 간주된다.

- 상용직 전환 간주 시: 4대보험 의무 가입 + 퇴직금 발생
- 건설업 이외 업종에서 법적 일용직으로 인정되는 범위는 매우 좁다
- 실무 분쟁 포인트: 근로자가 노동부에 체불임금 진정 시 고용 일수·출근부·급여 지급 내역 전체가 조사 대상이 된다

#### 2. 산재보험 미가입의 위험

**1일이라도 근무하면 산재보험 의무 가입**이다. 미가입 상태에서 업무상 재해 발생 시:

- 사업주가 보험급여 전액 부담 (요양급여·휴업급여·장해급여)
- 산재보험료 미납 기간에 대한 과태료 부과
- 형사 처벌 가능성 (산업재해보상보험법 §6)

실무 분쟁 포인트: "계약서가 없었다", "일용직이라 몰랐다"는 항변은 사업주 면책 사유가 되지 않는다. 1일 근무자도 동일하게 적용된다.

#### 3. 원천징수 신고 의무

일당 **150,000원 초과** 시 다음 달 10일까지 세무서에 신고해야 한다.

```
소득세:     (일당 - 150,000원) × 6% × 55% ≈ 일당의 2.7%
지방소득세:  소득세 × 10% ≈ 일당의 0.27%

예시: 일당 200,000원
  → 소득세 1,650원 + 지방소득세 165원 = 1,815원 공제
  → 실 수령액 198,185원
```

미신고·미납 시 가산세(미납세액의 10% + 이자상당액)가 부과된다. 여러 명에게 반복 지급하면서 미신고하면 세무조사 대상이 된다.

#### 4. 계속 고용 전환 위험

**3개월 이상** 동일 사업장에서 반복 고용되면 고용보험법상 일용직으로 보지 않는다.

- 근로자가 실업급여 신청 시 사업주가 "일용직이었다"고 소명해야 한다
- 소명 실패 시 실업급여 반환 명령 및 사업주 제재 가능
- 실무 분쟁 포인트: 근무일지·급여 지급 내역이 3개월 이상 연속되면 상용직 인정 가능성이 높다

#### 5. 주휴수당 잠재 리스크

주 15시간 이상 반복 근무하면 근로자가 주휴수당을 청구할 수 있다.

- 계약서에 "본 계약은 1일 단위로 고용관계가 종료되며, 다음 날 고용은 별도의 계약에 의한다"는 문구를 반드시 명시해야 한다
- 이 문구가 없으면 법원에서 계속 고용관계로 인정할 가능성이 있다
- 실무 분쟁 포인트: 주 15시간 이상 고용한 사실이 입증되면 소급 주휴수당 청구가 가능하다

#### 6. 건설업 특례 (건설 일용직 해당 시)

건설 일용직은 고용보험법 §15 특례 적용으로 일반 일용직과 다르게 취급된다.

- 월 기준 미충족이어도 고용보험 가입 가능
- 건설업 고용보험 일용직 신고는 다음 달 **15일**까지 (일반 사업장의 다음 달 10일과 다름)
- 건설 일용직 고용보험료: 사업주 0.9% + 근로자 0.9% (실업급여 기준, 2026년)
- 현장 단위 신고이므로 현장 변경 시 별도 신고 필요

### 4대보험 가입 기준 판단표

| 구분 | 적용 기준 | 비고 |
|------|-----------|------|
| 산재보험 | 1일이라도 근무 시 의무 | 예외 없음 |
| 고용보험 | 1개월 미만 또는 월 60시간 미만 → 해당 없음 | 3개월 이상 계속 → 의무 |
| 국민연금 | 1개월 미만 → 해당 없음 | 1개월 이상·월 60시간 이상 → 의무 |
| 건강보험 | 1개월 미만 → 해당 없음 | 1개월 이상·월 60시간 이상 → 의무 |
| 건설 고용보험 특례 | 건설업 일용직 → 별도 기준 적용 | 고용보험법 §15 |
