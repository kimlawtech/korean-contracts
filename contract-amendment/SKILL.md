## 핵심 법리 (변경 합의서 특유)

### 근로조건 변경의 원칙

```
근로기준법 §4 — 근로조건은 근로자와 사용자가 동등한 지위에서 자유의사로 결정

불이익 변경 금지 원칙:
  - 임금 삭감·수당 폐지 등 근로자에게 불리한 변경은 반드시 근로자 동의 필요
  - 동의 없는 취업규칙 불이익 변경 무효 (대법원 일관 판례)
  - 집단적 동의 필요 시: 근로자 과반수 동의

유리한 변경:
  - 임금 인상, 근무시간 단축 등 → 근로자 동의 없이도 가능
  - 단, 서면으로 합의서 작성해 분쟁 예방 권장
```

### 변경 합의서 vs. 신규 근로계약서

```
변경 합의서:  기존 계약의 특정 조항만 수정. 나머지는 기존 계약 유지.
신규 계약서:  기존 계약 전체를 새 내용으로 대체.

→ 일부 조건만 바뀌면 변경 합의서 사용
→ 대규모 조건 변경(3개 항목 이상)이면 신규 계약서 권장
```

## 동작 순서

### 1단계: 변경 유형 확인

```
어떤 근로조건을 변경하시나요? (복수 선택 가능)

① 임금 변경 (기본급·수당 증감)
② 근무장소 변경
③ 업무내용·직책 변경
④ 근무시간 변경
⑤ 기타 (구체적으로 알려주세요)
```

### 2단계: 기존 계약 기준 정보 수집

```
기존 근로계약서의 주요 내용을 알려주세요:
- 근로자 성명
- 사용자(회사)명
- 현재 임금 (변경 관련 시)
- 현재 근무장소 (변경 관련 시)
- 현재 업무내용 (변경 관련 시)
- 원래 계약 시작일
```

### 3단계: 변경 내용 수집

각 변경 유형별로 before → after 정보 수집:
- 변경 전 조건
- 변경 후 조건
- 변경 시행일
- 변경 사유 (선택)

### 4단계: 최저임금 검증 (임금 변경 시)

```
변경 후 시급 환산 = 변경 후 기본급 / (주소정근로시간 × 4.345)
2026년 최저임금 10,320원 미달 시 → 경고 출력, 생성 금지
```

### 5단계: 불이익 변경 경고

```
변경 내용이 근로자에게 불이익인지 자동 판단:
- 임금 삭감·수당 폐지 → ⚠️ 불이익 변경 경고 출력
- 근무시간 증가 (실질 임금 감소 효과) → ⚠️ 경고
- 근무장소 원거리 변경 → ⚠️ 협의 필요 안내

경고 문구 출력 후 진행 여부 확인 (생성은 가능, 단 경고 삽입)
```
