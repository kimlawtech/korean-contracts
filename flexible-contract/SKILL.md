## 동작 순서

### 1단계: 유연근무 유형 선택

```
어떤 유연근무제를 적용하시나요?

1) 탄력적 근로시간제
   → 바쁜 달엔 더 일하고, 여유 있는 달엔 덜 일하는 방식
   → 예: 프로젝트 기간엔 주 50시간, 이후엔 주 30시간
   → 근로자대표와 서면합의 필수 (없으면 도와드릴게요)

2) 선택적 근로시간제
   → 출퇴근 시간을 직원이 자유롭게 정하는 방식
   → 예: 코어타임 10:00~15:00, 나머지 자유
   → 취업규칙 + 서면합의 필수

3) 재택·원격근무
   → 집 또는 원하는 장소에서 근무
   → 계약서에 취업장소 명시 필수

4) 복합 (예: 선택근로 + 재택)
```

### 2단계: 사업장 규모·기본 정보

표준 근로계약서 인터뷰 진행 (사업장 규모, 임금, 4대보험 등).

### 3단계: 유형별 추가 질문

**탄력근로 선택 시:**
```
1. 정산 단위 기간 (예: 2주, 1개월, 3개월)
2. 단위 기간 내 주별 최대 근로시간
3. 근로자대표 지정 여부
   → 없으면: "근로자대표 선정 절차 안내"
```

**선택근로 선택 시:**
```
1. 코어타임 (필수 근무 시간대, 예: 10:00~15:00)
2. 플렉스타임 (자유 시간대)
3. 정산 기간 (1개월 단위 일반적)
4. 취업규칙 유무
   → 없으면: "취업규칙 작성 필요 안내"
```

**재택근무 선택 시:**
```
1. 재택 비율 (예: 주 3일 재택, 주 2일 출근)
2. 업무 보고 방식
3. 장비·통신비 지원 여부
4. 재택 불가 사유 명시 여부
```

### 4단계: 서면합의서 필요 여부 안내

탄력근로·선택근로 선택 시 반드시 안내:
```
[중요 안내]
탄력적/선택적 근로시간제는 계약서 외에
'근로자대표와의 서면합의서'가 별도로 필요해요.

서면합의서 없이 운영하면 법 위반이에요.
계약서 생성 후 서면합의서 작성을 도와드릴까요?
```

### 5단계: 최저임금 검증

```
탄력근로: 정산 기간 평균 주 40시간 이하인지 확인
선택근로: 정산 기간 총 소정근로시간 기준으로 최저임금 검증
시급 환산 < 10,320원 → 경고 출력, 생성 금지
```
