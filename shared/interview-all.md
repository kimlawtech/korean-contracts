# 사용자 인터뷰 — 계약서 유형별 질문

## 핵심 원칙

1. 전문용어 금지 — 등장 시 즉시 풀어쓰기
2. 예시 1개 이상 — 매 질문마다
3. 왜 묻는지 배경 설명
4. 선택지 제공
5. "모르면 넘어가도 됨" — 선택 항목에만 포함. 시급·일당·근무일자·당사자 정보 등 필수 항목에는 절대 붙이지 말 것
6. 공포 유발 금지
7. 모든 인터뷰 마지막에 반드시 저장 폴더를 물어볼 것 (Step SAVE)

---

## Step -1. 기존 계약서 확인 (모든 스킬 시작 시 최우선 확인)

```
기존에 사용하던 계약서가 있으신가요?

1) 있음 — 파일을 붙여넣거나 내용을 공유해 주세요.
   → 기존 계약서를 분석해서 수정·보완 후 새 계약서를 만들어드릴게요.
   → 형식·조항을 최대한 유지하면서 법적으로 부족한 부분만 보완합니다.

2) 없음 — 처음부터 새로 만들겠습니다.

기존 계약서가 있으면 인터뷰 항목 중 이미 포함된 내용은 건너뜁니다.
```

기존 계약서 제공 시 처리 방법:
- Read 툴 또는 붙여넣기로 내용 수신
- 계약 유형, 당사자 정보, 근무 조건, 임금 항목 자동 추출
- 누락·오류 항목만 추가 질문
- legal-validation-rules.md RULE 1~11 즉시 적용해 문제점 먼저 안내

## Step 0. 계약서 유형 선택

```
어떤 계약서가 필요하세요?

1) 근로계약서
   → 직원을 채용할 때 (정규직·계약직·아르바이트·단시간근로자)
   → 4대보험 가입, 근로기준법 보호 적용

2) 프리랜서 계약서
   → 개인 프리랜서나 1인 사업자에게 일을 맡길 때
   → 4대보험 없음, 3.3% 원천징수, 자유계약

3) 외주용역계약서
   → 다른 회사·법인에게 프로젝트를 발주할 때
   → 세금계산서 발행, 결과물·납기 중심

잘 모르시면: 개인한테 맡기면 1) 또는 2), 회사한테 맡기면 3)이에요.
```

## [근로계약서] 인터뷰

### Step 1. 고용주 정보

```
먼저 고용하는 쪽(사업주) 정보를 알려주세요.

1. 회사명 (또는 상호명)
   예: 주식회사 모카, 홍길동 개인사업자

2. 대표자 이름
   예: 홍길동

3. 사업장 주소
   예: 서울 강남구 테헤란로 123

4. 사업자등록번호
   예: 123-45-67890
   모르시면 "모름"으로 두셔도 됩니다 (나중에 기입하시면 돼요).
```

### Step 2. 근로자 정보

```
채용할 직원 정보를 알려주세요.

1. 이름 (예: 이직원)
2. 주민등록번호 앞 6자리 (예: 950101)
   → 뒤 7자리는 보안상 "●●●●●●●"으로 처리합니다.
3. 주소 (예: 서울 서초구)
4. 연락처 (예: 010-1234-5678)
```

### Step 3. 고용 형태

```
어떤 형태로 고용하시나요?

1) 정규직 — 기간 없이 계속 근무
2) 계약직 — 기간 정해서 근무 (예: 6개월, 1년)
3) 단시간 근로자 (아르바이트) — 주 15시간 미만 또는 파트타임

※ 계약직을 2년 이상 쓰면 자동으로 정규직 전환 의무가 생겨요.
   (기간제 및 단시간근로자 보호 등에 관한 법률)
```

계약직이면:
```
계약 기간을 알려주세요.
예: 2026-05-01 ~ 2026-10-31 (6개월)

계약 만료 후 어떻게 하실 계획인가요?
1) 갱신 협의
2) 종료
3) 미정
```

### Step 4. 업무 내용·근무지

```
어떤 일을 하게 되나요?

1. 직책/직무 (예: 마케터, 백엔드 개발자, 매장 서비스)
2. 주요 업무 설명 (예: SNS 콘텐츠 기획·운영, Instagram·블로그 관리)
3. 근무지 (예: 서울 강남구 본사 / 재택근무 가능)
```

### Step 5. 근로 시간

```
근무 시간을 알려주세요.

1. 주 근무일수 (예: 주 5일, 주 3일)
2. 하루 근무 시간 (예: 9:00~18:00, 점심 1시간 제외 → 8시간)
3. 휴게 시간 (예: 12:00~13:00)

※ 주 40시간 초과하면 연장근로 수당(50% 가산)이 발생해요.
   주 15시간 미만이면 주휴수당·연차가 없어요.
```

### Step 6. 임금

```
임금(급여)을 알려주세요. 법에서 가장 중요하게 보는 항목이에요.

1. 임금 형태
   1) 월급 (예: 월 3,000,000원)
   2) 시급 (예: 시간당 12,000원)
   3) 일급 (예: 하루 100,000원)

2. 금액 (예: 3,000,000원)

3. 포함 내역
   - 기본급만인가요, 아니면 식대·교통비 같은 수당이 포함되나요?
   예: 기본급 2,700,000 + 식대 200,000 + 교통비 100,000

4. 지급일 (예: 매월 25일)

5. 재직조건부 상여금이 있나요?
   → 재직 중인 경우에만 지급하는 조건부 상여금인지 여부를 확인해요.
   → 2024.12.19. 대법원 전원합의체 판결로 재직조건부 상여금도 통상임금에 포함돼요.
   → 상여금이 통상임금에 포함되면 연장·야간·휴일수당 계산 기준이 높아질 수 있어요.
   1) 없음
   2) 있음 — 지급 기준 (예: 재직 중인 자에게 연 2회 지급 등)

6. 임금명세서 교부 방식
   → 매월 임금 지급 시 임금명세서를 교부해야 해요 (미교부 시 과태료 최대 100만원).
   1) 이메일
   2) 문자(SMS)
   3) 사내 앱·시스템
   4) 종이 출력물 수령

※ 2026년 최저임금: 시간당 10,320원 (월 209시간 환산 시 2,156,880원)
   이것보다 적으면 법 위반이에요. 자동으로 체크해드려요.
```

### Step 7. 휴일·휴가

```
휴일과 휴가를 알려주세요.

1. 주휴일 (예: 매주 일요일)
   → 주 15시간 이상 근무하면 주 1회 유급 휴일이 의무예요.

2. 연차유급휴가
   → 1년 만근 시 15일이 법정 기준이에요. 추가 부여 하실 건가요?
   1) 법정 기준만 (15일)
   2) 법정 기준 + 추가 부여 (예: 20일)

3. 공휴일 적용
   1) 법정 공휴일 유급으로 모두 적용 (5인 이상 사업장 의무)
   2) 일부만 적용
   3) 사업장 규모 확인 필요
```

### Step 8. 4대보험

```
4대보험(국민연금·건강보험·고용보험·산재보험)을 가입하실 건가요?

1) 모두 가입 (권장, 주 15시간 이상이면 의무)
2) 산재보험만 가입 (주 15시간 미만 초단시간)
3) 별도 논의 필요

※ 정규직·계약직이면 대부분 4대보험 의무예요.
   모르시면 "모두 가입"으로 두시면 됩니다.
```

### Step 9. 수습 기간

```
수습 기간이 있나요?

수습 기간이란: 처음 입사 후 업무 적응 기간이에요.
이 기간엔 임금을 최저임금의 90%까지 낮출 수 있어요 (3개월 한도).

1) 없음
2) 있음 → 기간과 수습 임금 알려주세요
   예: 3개월 수습, 수습 기간 급여 2,700,000원
```

### Step 10. 퇴직금

```
퇴직금 지급 방식을 알려주세요.

법적으로 1년 이상 근무한 직원에게 퇴직금을 줘야 해요.
(월 임금 × 재직 연수 기준)

1) 퇴직 시 일시 지급 (기본)
2) 퇴직연금 (DC형·DB형) 운영
3) 계약직이라 해당 없음 (1년 미만)
```

### Step 11. 기타 조항

```
추가로 넣고 싶은 조항이 있나요?

아래 중 해당되는 것을 골라주세요:

[ ] 비밀유지 의무 (회사 정보·고객 정보 유출 금지)
[ ] 경업금지 (퇴직 후 동종업계 취업 제한 — 기간·지역 제한 있어야 유효)
[ ] 겸업금지 (재직 중 다른 회사 취업 금지)
[ ] 지식재산권 (업무 중 만든 결과물은 회사 소유)
[ ] 배우자 출산휴가 조항 명시
   → 2025년부터 배우자 출산휴가는 20일(유급)로 확대됐어요.
   → 출산일로부터 120일 이내 사용, 사업주 승인 없이 청구 가능해요.
   → 계약서에 별도 명시를 원하시면 선택해주세요.

없으면 "없음"으로 넘어가도 됩니다.
```

## [프리랜서 계약서] 인터뷰

### Step F1. 당사자 정보

```
계약 양쪽 정보를 알려주세요.

[발주자 (일 주는 쪽)]
1. 이름 또는 회사명 (예: 주식회사 모카)
2. 대표자명
3. 연락처·이메일

[수주자 — 프리랜서 (일 받는 쪽)]
1. 이름 (예: 김디자이너)
2. 연락처·이메일
3. 주민번호 앞 6자리 (원천징수 신고용)
   → 개인사업자라면 사업자번호도 OK
```

### Step F2. 업무 범위

```
어떤 일을 맡기시나요? 구체적일수록 분쟁이 줄어요.

1. 업무명 (예: 모바일 앱 UI 디자인)
2. 상세 설명 (예: iOS/Android 앱 전체 화면 30개 디자인, Figma 파일 납품)
3. 결과물 (예: Figma 파일, PNG 에셋, 디자인 가이드 PDF)

모호한 범위는 나중에 "이것도 해달라" 분쟁의 원인이에요.
```

### Step F3. 계약 금액·지급

```
돈 얼마를 어떻게 드릴 건가요?

1. 총 계약 금액 (예: 3,000,000원)
2. 지급 방식
   1) 일시 지급 (완료 후 전액)
   2) 분할 지급 (예: 착수금 30% + 완료 시 70%)
   3) 마일스톤 지급 (예: 1차 시안 승인 시 50%, 최종 완료 시 50%)

3. 원천징수 방식
   1) 3.3% 원천징수 (개인 프리랜서 — 일반적)
   2) 부가세 포함 세금계산서 (개인사업자 — 선택)

※ 3.3%란: 소득세 3% + 지방소득세 0.3%예요.
   발주자가 떼고 세무서에 납부하는 거예요.
```

### Step F4. 일정·납기

```
언제까지 완료해야 하나요?

1. 계약 기간 (예: 2026-05-01 ~ 2026-06-30)
2. 중간 마일스톤이 있나요?
   예: 1차 시안 제출 2026-05-20, 최종 납품 2026-06-30
3. 납기 지연 시 어떻게 하실 건가요?
   1) 지체상금 없음
   2) 지체 1일당 계약금의 0.1% 차감 (일반적)
   3) 협의로 결정
```

### Step F5. 지식재산권

```
프리랜서가 만든 결과물의 권리는 누구 것이 될까요?

이게 중요한 이유: 명시 안 하면 나중에 분쟁 생겨요.

1) 발주자(사업주)가 모든 권리 소유 — 가장 일반적
2) 프리랜서가 저작권 보유, 발주자에게 사용 허락만
3) 저작권은 프리랜서, 저작재산권만 발주자에게 양도
4) 협의로 별도 결정

모르시면 1번을 고르시면 돼요.
```

### Step F6. 비밀유지·기타

```
추가 조항을 선택해주세요:

[ ] 비밀유지 의무 (NDA) — 업무 관련 정보 외부 공개 금지
[ ] 경업금지 — 계약 기간 중 경쟁사 동일 업무 금지
[ ] 재하도급 금지 — 다른 사람에게 재위탁 불가
[ ] 수정 횟수 제한 (예: 3회 이내, 초과 시 추가 비용)

없으면 "없음"으로 넘어가세요.
```

## [외주용역계약서] 인터뷰

### Step O1. 당사자 정보

```
계약 양쪽 회사 정보를 알려주세요.

[발주사 (일 주는 쪽)]
1. 회사명 (예: 주식회사 ABC)
2. 대표자명
3. 사업자등록번호
4. 주소
5. 담당자 이름·연락처

[수주사 (일 받는 쪽)]
1. 회사명 (예: 주식회사 XYZ)
2. 대표자명
3. 사업자등록번호
4. 주소
5. 담당자 이름·연락처
```

### Step O2. 용역 범위

```
어떤 프로젝트를 맡기시나요?

1. 용역명 (예: 쇼핑몰 웹사이트 개발)
2. 상세 범위 (예: 회원가입·상품 등록·결제·배송 추적 기능 포함)
3. 납품 산출물 (예: 소스코드, 배포 서버, 운영 매뉴얼)
4. 제외 사항 (예: 서버 운영 비용, 제3자 API 비용 제외)
```

### Step O3. 계약 금액

```
계약 금액과 지급 방식을 알려주세요.

1. 총 계약 금액 (예: 50,000,000원, 부가세 별도/포함)
2. 지급 방식
   1) 착수금 30% + 중도금 40% + 잔금 30%
   2) 마일스톤별 지급 (예: 기획 완료 시 20%, 개발 완료 시 50%, 검수 후 30%)
   3) 완료 후 일시 지급
3. 부가세 처리
   1) 부가세 별도 (계약금액 + VAT 10%)
   2) 부가세 포함
```

### Step O4. 일정·납기

```
일정을 알려주세요.

1. 계약 기간 (예: 2026-05-01 ~ 2026-09-30)
2. 주요 마일스톤 (예: 기획서 2주 내, 개발 완료 3개월 내, 검수 1주)
3. 지체상금
   1) 없음
```

## 공통 Step SAVE: 저장 폴더 선택 (필수 — 최종 확인 후 반드시 진행)

최종 확인 후 계약서 생성 전에 반드시 저장 위치를 물어볼 것.

```
계약서를 어디에 저장할까요?

1) 바탕화면 (~/Desktop)
2) 다운로드 폴더 (~/Downloads)
3) 직접 입력 — 폴더 경로를 알려주세요
   예: /Users/홍길동/Documents/계약서

선택하시면 .txt 와 .docx 두 가지 형식으로 저장해드릴게요.
```

- 기본값: `~/Desktop`
- 경로가 존재하지 않으면 생성할 것 (mkdir -p)
