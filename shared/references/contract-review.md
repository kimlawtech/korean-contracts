# 기존 계약서 검토 프로토콜

모든 스킬은 시작 시 이 프로토콜을 따라 기존 계약서를 분석한다.

---

## [검토 모드] 진입 조건

사용자가 기존 계약서를 제공한 경우 → 신규 작성 대신 이 파일의 프로토콜 실행.

```
기존 계약서를 분석해서 세 가지를 먼저 드립니다.

1) 법적 위험 항목 — 즉시 수정이 필요한 위반 사항
2) 개정법령 반영 여부 — 최근 바뀐 법·판례 기준 미달 항목
3) 개선 권고 — 위반은 아니지만 분쟁 예방을 위해 보완하면 좋은 항목

분석 후 수정안을 제안하겠습니다. 채택하실 항목만 골라주시면 계약서를 재작성합니다.
```

---

## [1단계] 계약서 수신 방법

```
기존 계약서를 아래 방법 중 하나로 공유해 주세요.

1) 내용을 직접 붙여넣기 (텍스트 복사)
2) 파일 경로 알려주기 (예: ~/Desktop/계약서.txt)
   → Read 툴로 직접 읽겠습니다.
```

파일 경로 제공 시: Read 툴로 읽는다.
붙여넣기 시: 그대로 수신해 분석한다.

---

## [2단계] 자동 분류

계약서 내용에서 아래 항목을 자동으로 추출한다.

| 추출 항목 | 방법 |
|-----------|------|
| 계약 유형 | 제목·조항 패턴으로 판별 (근로/알바/프리랜서/외주/일용직 등) |
| 당사자 정보 | 사업자명·근로자명·사업자번호 |
| 계약 기간 | 시작일·종료일 또는 "기간의 정함 없음" |
| 임금 | 금액·구성항목·지급일 |
| 근로시간 | 소정근로시간·휴게시간 |
| 사업장 규모 | 5인 이상/미만 명시 여부 |
| 작성 시점 추정 | 최저임금 금액 등으로 연도 추정 |

## [3단계] 개정법령 비교 체크리스트

추출 완료 후 아래 기준으로 순서대로 비교한다.

### A. 2026년 최저임금 (10,320원/시)

```
계약서 시급/월급 → 시급 환산 → 10,320원 이상 여부 확인
미달 시: ❌ 위반 — 즉시 수정 필요
```

### B. 대법원 2024.12.19. — 통상임금 고정성 폐지

```
체크 대상: 재직조건부 상여금, 특정 기간 근무 조건부 수당
"재직자에게만 지급" 조건으로 통상임금 제외 처리된 항목 → 포함으로 재산정 필요

오류 패턴:
- "재직자에 한하여 지급" + OT·야간·휴일수당 산정에서 제외 → ⚠️ 수정 권고
- 포괄임금 계약에서 고정성 기준 통상임금 산정 → ⚠️ 재산정 필요
```

### C. 대법원 2024.12.26. — 포괄임금 최저임금 미달 무효

```
체크: 기본급만으로 최저임금 이상인가 (연장수당 합산 불가)
기본급이 최저임금 미달이면 그 부분은 무효 → ❌ 수정 필요
```

### D. 배우자 출산휴가 20일 (2025년 시행)

```
남녀고용평등법 §18의2 개정: 10일 → 20일 (유급)
적용 시작: 2025.02.23.

계약서에 배우자 출산휴가 조항이 있고 10일로 기재된 경우 → ⚠️ 20일로 수정 권고
조항 자체가 없는 경우 → ⚠️ 추가 권고 (법적 의무 사항)
```

### E. 임금명세서 교부 의무 (2021.11.19. 시행)

```
근로기준법 §48②: 임금 지급 시 명세서 교부 의무
미명시 계약서 → ⚠️ 조항 추가 권고 (위반 시 과태료 최대 500만원)
```

### F. 연장·야간·휴일 가산수당 §56 (5인 이상)

```
5인 이상 사업장:
- 연장근로: 통상임금 × 1.5
- 야간근로(22:00~06:00): 통상임금 × 1.5
- 휴일근로: 8시간 이내 × 1.5 / 8시간 초과 × 2.0

계약서에 5인 이상임에도 가산수당 조항 없음 → ⚠️ 추가 권고
```

### G. 갱신기대권 방지 문구 (기간제 계약)

```
2년 이내 기간제 계약:
- 갱신 여부를 명확히 명시하지 않으면 갱신기대권 발생 가능
- "이 계약은 기간 만료로 자동 종료되며, 갱신을 보장하지 않는다" 문구 확인
미포함 시 → ⚠️ 추가 권고
```

### H. 하도급법 2024.8.28. — 기술자료 5배 손해배상 (외주용역에 한함)

```
수탁사 기술자료 무단 사용·제3자 제공 금지 (§35②)
위반 시 5배 손해배상
외주용역 계약서에 기술자료 보호 조항 없음 → ⚠️ 추가 권고
```

### I. 단시간 근로자 요일별 근로시간 테이블 (기간제법 §17②)

```
단시간 근로자(알바·파트타임):
요일별 근로시간 테이블 미명시 → ❌ 위반 (기간제법 §17②)

| 요일 | 근무 시작 | 근무 종료 | 휴게 | 실 근로시간 |
테이블 형식 필수
```

```
[기존 계약서 분석 결과]

계약 유형: 근로계약서 (정규직, 추정)
작성 시점: 2024년 추정 (최저임금 9,860원 기재)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## [5단계] 수정안 적용 및 재작성

사용자가 수정 항목을 선택하면:

1. 기존 계약서 내용을 기반으로 선택 항목만 수정
2. 나머지 조항은 원문 그대로 유지
3. 수정된 계약서에 RULE 1~14 재적용
4. `.txt` + `.docx` 파일 생성

출력 형식:
```
[수정 완료]
원본 대비 변경 사항:
  - 제7조 임금: 2,097,900원 → 2,156,880원
  - 제8조 임금명세서 교부 조항 추가
  - 제9조 배우자 출산휴가: 10일 → 20일
  - 제10조 통상임금 재직조건부 상여금 포함 문구 추가

[생성 완료]
  📄 employment-contract-홍길동-20260420.txt (수정본)
  📄 employment-contract-홍길동-20260420.docx (수정본)

서명 전 노무사·변호사 검토를 권장합니다.
```

## 계약서 유형별 추가 검토 포인트

### 알바·단시간 계약서
- 주 소정근로시간 실제 계산 (요일별 × 시간) vs. 계약서 기재값 일치 여부
- 주 15시간 이상임에도 주휴수당 조항 없는 경우 → 추가

### 프리랜서 계약서
- 위장 프리랜서 7대 요소 (대법원 2006다49830) 체크
- 원천징수 3.3% 조항 존재 여부

### 외주용역 계약서
- 하도급법 §3 필수 7항목 누락 여부
- 불법파견 방지 독립계약자 관계 조항 존재 여부
- 기술자료 보호 조항 (5배 손해배상 근거)

### 연봉계약서
- 임금 구성 항목 분리 여부 (기본급 + 수당 명시)
- 포괄임금 기본급 분리 여부

### 근로조건 변경 합의서
- 불이익 변경 여부 자동 판단
- 소급 적용 금지 문구 존재 여부
- 변경 시행일 명시 여부
