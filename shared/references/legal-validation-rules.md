# 계약서 법률 검증 룰

계약서 생성 후 이 파일의 RULE 1~14를 순서대로 적용해 자체 검토할 것.
(RULE 12~14는 근로계약·프리랜서·외주용역 계약서에 해당하는 경우에만 적용)
오류 발견 시 계약서를 수정한 뒤 재저장. 사용자에게 오류 내용과 수정 내역을 알릴 것.

---

## RULE 1. 계약 유형 일치성 검증

**체크:** 계약서 제목·본문의 근로자 유형이 실제 근무 조건과 일치하는가

| 조건 | 올바른 유형 |
|------|-----------|
| 주 소정근로시간 = 40시간 | 통상 근로자 → 기간제 or 정규직으로 표기 |
| 주 소정근로시간 < 40시간 | 단시간 근로자 |
| 1일 단위 고용 | 일용근로자 |

**오류 패턴:**
- 주 40시간인데 "단시간 근로자" 표기 → 기간제/정규직으로 수정
- 단시간인데 §9 단시간보호 조항 없음 → 추가
- 일용직인데 고정 월급 표기 → 일당으로 수정

## RULE 2. 최저임금 검증 (2026년: 10,320원/시)

**계산식:**
```
시급제: 입력 시급 ≥ 10,320원
월급제(주40h): 월급 ÷ 209시간 ≥ 10,320원  → 최저 월급 2,156,880원
월급제(주X시간): 월급 ÷ (X × 4.345 + 주휴시간) ≥ 10,320원
일당제: 일당 ÷ 실근로시간 ≥ 10,320원
포괄임금: 기본급만으로 검증 (연장수당 제외)
```

**오류 패턴:**
- 최저임금 미달 → 생성 중단, 경고 출력
- 포괄임금에서 기본급+OT 합산 계산 → 기본급 단독으로 재계산

## RULE 3. 5인 기준 분기 검증

**체크:** 사업장 규모가 올바르게 반영됐는가

| 항목 | 5인 미만 | 5인 이상 |
|------|---------|---------|
| 가산수당 §56 | 의무 없음 — "통상임금 지급" 문구 사용 | 연장·야간·휴일 50% 가산 의무 |
| 법정공휴일 유급 | 의무 없음 — 계약서에 명시 | 유급 의무 |
| 연차유급휴가 §60 | 의무 없음 (부여 시 명시) | 15일 의무 |
| 부당해고 구제신청 §28 | 불가 | 가능 |
| 근로자의 날 유급 | 의무 (규모 무관) | 의무 |

**오류 패턴:**
- 5인 이상인데 "가산수당 미적용" 문구 → §56 기준으로 교체
- 5인 미만인데 가산수당 50% 조항 → 삭제 후 "통상임금 지급"으로 교체
- 5인 미만인데 연차 15일 의무 표기 → 임의 부여임을 명시
- 규모 미확인 → 사용자에게 확인 요청 후 진행

---

## RULE 4. 근로기준법 §17 필수 5개 항목 완비

계약서에 아래 5개가 모두 있는지 확인:

- [ ] 임금 구성항목·계산방법·지급방법·지급일 (확정 날짜 필수 — "협의" 금지)
- [ ] 소정근로시간 (시업·종업·휴게 포함)
- [ ] 휴일 (주휴일 + 법정공휴일 처리 명시)
- [ ] 연차유급휴가 (5인 이상만 의무 — 5인 미만은 임의 부여 여부 명시)
- [ ] 근무장소 및 업무내용 (포괄 기재 금지)

**오류 패턴:**
- 근무장소 "서초구" 등 지역명만 → 구체 주소 요청
- 업무내용 "서류 작성", "기타 업무" → 구체화 요청
- 임금 지급일 "협의하여 결정" → 확정 날짜로 교체

## RULE 5. 임금 지급 방식 명확성

**체크:** 시급제 vs 월급제가 명확히 구분되는가

```
월급제 (풀타임 권장):
  → "월 OOO원 (주휴 포함, 통상임금 산정 기준 209시간)" 명시
  → 지각·조퇴 공제 기준 명시

시급제:
  → 주휴수당 "별도 지급" or "포함" 명시 필수
  → 월 정산 기준 명시
```

**오류 패턴:**
- 시급제인데 주휴수당 언급 없음 → 추가
- 월 209시간 기준인데 주휴 포함 여부 미명시 → 명시

## RULE 6. 연차 일수 정확성

**계산 기준:**
```
기간제 계약:
  - 계약 기간 N개월 기준 최대 (N-1)일 (1개월 개근 시 익월 1일 발생)
  - 예: 6개월 계약 → 최대 5일 (2~6개월 개근분)
  - 11일은 1년 미만 전체 기준 — 6개월 계약에 11일 부여는 과다

1년 이상 계약:
  - 1년 미만: 최대 11일 (매월 개근 시 1일)
  - 1년 이상: 15일
```

**오류 패턴:**
- 6개월 계약인데 연차 11일 → 5일로 수정 또는 사용자 확인
- 계약 기간 대비 과다한 연차 일수 → 경고 출력 후 확인

## RULE 7. 계약 기간·종료일 검증

```
정규직(무기계약): 종료일 없음 → "기간의 정함 없음" 명시
기간제: 시작일·종료일 모두 필수
  → 2년 초과 시 무기계약 전환 경고 (기간제법 §4)
일용직: 근무 일자 목록 필수
```

**오류 패턴:**
- 기간제인데 종료일 공란 → 사용자 재확인
- 2년 초과 → 경고: "무기계약 전환 의무 발생 가능"

---

## RULE 8. 해고예고 조항 정확성

```
적용 기준:
- 계속근로 3개월 미만 → 해고예고 의무 없음 (§26 단서)
- 계속근로 3개월 이상 → 30일 전 예고 or 30일분 임금
- 해고 사유 서면 통지 의무 (§27): 5인 이상만 적용

5인 미만도 §26 해고예고는 적용됨
```

**오류 패턴:**
- "3개월 미만 예고 불요" 단서 없음 → 추가
- 5인 미만인데 §27 서면 통지 의무 표기 → 삭제

---

## RULE 9. 수습 조항 검증

```
수습 기간: 최대 3개월
수습 임금 감액:
  - 1년 이상 계약: 최저임금 90%까지 감액 가능
  - 1년 미만 기간제: 감액 불가 (최저임금법 §5)
```

**오류 패턴:**
- 6개월 기간제인데 수습 90% 감액 → 경고: "1년 미만 기간제 수습 감액 불가"

## RULE 10. 상시 근로자 수 산정 안내

**체크:** 5인 기준 분기 전 상시 근로자 수 확인 요청

```
산정 방법:
  법 적용 사유 발생일 전 1개월간 연인원 ÷ 가동일수

포함 대상:
  - 정규직, 계약직, 단시간 근로자, 대표이사(근로 제공 시) 모두 포함
  - 파견 근로자 제외

분기 기준:
  - 4명 이하 → 5인 미만
  - 5명 이상 → 5인 이상
```

**오류 패턴:**
- 대표 포함 여부 미확인 상태로 5인 미만 적용 → 확인 요청
- 계약직 다수인데 5인 미만 주장 → 재산정 요청

## RULE 11. 당사자 정보 완비

**체크:** 공란 항목을 사용자에게 알릴 것

사용자(고용주):
- [ ] 사업자명
- [ ] 대표자명
- [ ] 사업자등록번호
- [ ] 구체 주소 (시·구·로·번지까지)

근로자:
- [ ] 성명
- [ ] 주민등록번호 앞 6자리
- [ ] 구체 주소
- [ ] 연락처

## RULE 12. 통상임금 고정성 폐지 검증 (2024.12.19 대법원 전원합의체)

**체크:** 재직조건부 상여금·특정 기간 근무 조건부 금품이 통상임금에서 제외되어 있는가

```
2024.12.19 대법원 전원합의체 판결:
  기존 "고정성" 요건 폐지 → 소정근로 대가이면 통상임금 해당
  재직 조건부 상여금도 정기성·일률성 충족 시 통상임금 포함

검증 대상:
  - 재직자 조건 상여금 (명절·하계 등)
  - 특정 근무일 수 조건부 수당
  - 성과급 중 전 직원 일률 지급분
```

**오류 패턴:**
- "재직 중인 자에게만 지급" 단서로 통상임금 제외 처리 → 2024.12 판결 이후 포함 가능성 경고
- 포괄임금제 계약에서 고정성 기준 통상임금 산정 → 재산정 필요 경고
- 재직조건부 상여금을 OT·야간·휴일수당 산정에서 누락 → 수정 요청

## RULE 13. 임금명세서 교부 의무 조항 포함 여부

**체크:** 근로계약서 또는 별도 조항에 임금명세서 교부 의무가 반영되어 있는가 (근로기준법 제48조 제2항, 2021.11.19 시행)

```
임금명세서 필수 기재 항목:
  1. 근로자 성명·생년월일·사번
  2. 임금 지급일
  3. 임금 총액
  4. 임금 구성항목별 금액 (기본급, 각 수당 구분)
  5. 출근일수·근로시간 수 (시간급 등 계산 기준)
  6. 공제 항목별 금액 및 총액
  7. 실지급액
```

**오류 패턴:**
- 임금명세서 교부 조항 없음 → 추가 권고 (위반 시 500만원 이하 과태료)
- 임금 총액만 기재 → 항목별 명세 기재 의무 안내
- 전자 교부 가능 여부 미명시 → "전자적 방법 교부 가능" 문구 추가 권고

## RULE 14. 위장 프리랜서 7대 요소 체크 (프리랜서·용역 계약에 한해 적용)

**체크:** 프리랜서·외주용역 계약서에서 아래 7대 요소가 실질적으로 존재하는지 확인

```
위장 프리랜서 7대 판단 요소 (고용노동부 지침, 대법원 2006다49830 등):
  1. 발주사의 상시적·구체적 업무 지시 존재 여부
  2. 발주사 지정 장소·시간에 상시 출퇴근 여부
  3. 타사 겸업 금지 또는 전속 의무 강제 여부
  4. 발주사 제공 장비·자재로만 업무 수행 여부
  5. 보수가 근로 대가 성격 (정기적·고정적 지급) 여부
  6. 발주사가 인사·징계에 실질적으로 관여 여부
  7. 4대보험 미가입이 사실상 강제(당사자 의사 무관) 여부
```

**오류 패턴:**
- 프리랜서 계약인데 발주사 지정 시간·장소 상시 출근 조항 존재 → 근로자성 경고 출력
- 전속 의무(겸업 전면 금지) 조항 + 고정 월정액 지급 → 위장 프리랜서 고위험 경고
- 수탁자 소속 인원에 대한 발주사 직접 지시 조항 존재 → 불법파견 경고
- 독립 사업자 지위 조항(제5조) 없이 계약 체결 → 해당 조항 추가 권고
