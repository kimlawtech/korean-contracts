# 계약서 누락·위반 시 제재 및 리스크

## 근로계약서 관련

| 위반 사항 | 제재 |
|----------|------|
| 근로계약서 미작성 | 500만원 이하 벌금 (근로기준법 §114) |
| 근로계약서 미교부 | 500만원 이하 벌금 |
| 최저임금 미달 지급 | 3년 이하 징역 또는 2,000만원 이하 벌금 |
| 4대보험 미가입 (국민연금) | 과태료 최대 500만원 + 보험료 소급 부과 |
| 4대보험 미가입 (산재, 사고 발생 시) | 보험급여의 50% 징수 |
| 주휴수당 미지급 | 임금체불 (3년 이하 징역 또는 2,000만원 이하 벌금) |

## 프리랜서 계약서 관련

| 위반 사항 | 제재 |
|----------|------|
| 원천징수 미이행 | 가산세 (미납세액의 3%~10%) |
| 위장 프리랜서 적발 | 4대보험 소급 부과 + 가산금 |
| 지급명세서 미제출 | 과태료 1만원/건 (연간 제출) |

## 외주용역 계약서 관련

| 위반 사항 | 제재 |
|----------|------|
| 불법파견 (실질 지휘감독) | 파견법 위반 — 2년 이하 징역 또는 2,000만원 이하 벌금 |
| 하도급법 위반 (부당 단가 인하) | 공정위 시정명령·과징금 |
| 대금 미지급 (60일 초과) | 하도급법 위반 — 지연이자 연 40% |

## 일반 리스크

- 계약서 없는 구두 계약: 분쟁 시 내용 입증 불가
- 업무 범위 불명확: "이것도 해달라" 분쟁 가장 多
- 지식재산권 미명시: 결과물 소유권 분쟁
