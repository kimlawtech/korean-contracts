# 외주용역 도급·위임 구분 기준

## 도급계약 (외주용역의 일반 형태)

- 민법 제664조: "수급인이 어떤 일을 완성하면 도급인이 그 결과에 보수를 지급"
- 핵심: **결과물** 중심
- 예: 웹사이트 개발 완료 납품, 건물 시공 완료

## 위임계약 (자문·컨설팅)

- 민법 제680조: "당사자 일방이 상대방에 사무를 위탁"
- 핵심: **행위 과정** 중심 (결과 보장 X)
- 예: 법률 자문, 컨설팅 서비스, 회계 서비스

## 외주용역 계약 시 주의사항

### 불법 파견 주의
직접 지휘·감독하면 파견법 위반:
- 수주사 직원에게 직접 업무 지시 금지
- 수주사 직원의 출퇴근 관리 금지
- 수주사 직원이 발주사 내부 시스템에 상주 금지 (단, 현장 업무 성격이면 예외)

### 하도급법 적용 기준
원사업자가 수급사업자에게 제조·수리·건설·용역 위탁 시 하도급법 적용:
- 부당 단가 인하 금지
- 기술자료 요구 제한
- 대금 지급 60일 초과 금지

## 계약서 핵심 조항

1. **용역 범위 명확화**: 포함/제외 사항 명시 (분쟁 80%는 범위 분쟁)
2. **검수 기준**: 수치화된 인수 기준 (예: "기능 요구사항 100% 구현")
3. **변경 관리 (CR)**: 추가 요청 시 별도 견적·계약
4. **하자보증**: 6개월~1년 일반적
