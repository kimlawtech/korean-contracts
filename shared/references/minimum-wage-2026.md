- **월급** (주 40시간, 월 209시간 기준): 2,156,880원

## 최저임금 산입 범위

최저임금 계산에 **포함**:
- 기본급
- 정기적·일률적으로 지급되는 수당

최저임금 계산에 **미포함** (별도 지급):
- 식대 (월 20만원 이하 비과세분)
- 교통비
- 상여금 (연간 최저임금 총액의 25% 이하)
- 연장·야간·휴일 가산수당

## 주휴수당 계산

주 15시간 이상 개근 시 1일치 유급 주휴일 부여 (근로기준법 §55).

```
주휴수당 = (주 소정근로시간 / 40) × 8 × 시급
예: 주 40시간, 시급 12,000원 → 주휴수당 96,000원/주
예: 주 20시간, 시급 10,320원 → 주휴수당 41,280원/주
```

## 월 환산 근로시간

```
월 환산 = 주 소정근로시간 × (365/7/12) = 주 소정근로시간 × 4.345
주 40시간 → 209시간/월
주 30시간 → 156.5시간/월
주 20시간 → 104.3시간/월
주 15시간 → 65.2시간/월
```

## 최저임금 위반 판단 공식

```
시급 환산 = 월급 / 월 환산 시간
예: 월급 2,200,000 / 209 = 10,526원 → 2026년 최저임금(10,320원) 충족
예: 월급 2,100,000 / 209 = 10,048원 → 2026년 최저임금 미달 → 경고
```
