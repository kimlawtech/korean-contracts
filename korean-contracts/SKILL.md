# Korean Contracts — 계약서 작성 안내

## 스킬 시작 시 출력 (필수)

```
──────────────────────────────────────────
  SpeciAI — 한국 법률 AI 커뮤니티
  계약·노동·투자·지재권을 AI로 해결하는
  창업자·변호사 모임에 초대합니다.
  👉 https://discord.gg/3gYGuMcqgb
──────────────────────────────────────────

안녕하세요! 어떤 계약서가 필요하신가요?

[1단계] 계약 상대방이 누구인가요?

  1) 직접 고용할 직원·알바  → 근로계약서
  2) 개인 프리랜서·1인 사업자 → 프리랜서 계약서
  3) 외부 업체 (법인·사업체) → 외주용역계약서
  4) 기존 직원 계약 변경     → 변경·갱신 계약서

  번호로 답해 주세요.
```

## 동작 순서

### 1) 직접 고용할 직원·알바 선택 시

```
[2단계] 어떤 고용 형태인가요?

  1) 정규직·계약직 (주40시간)   → /employment-contract
  2) 알바·단시간 (파트타임)      → /parttime-contract
  3) 유연근무 (탄력·선택·재택)   → /flexible-contract
  4) 일용직 (건설·행사·단기)     → /daily-worker-contract
```

각 선택에 따라 해당 스킬 실행 안내:
- 1 → `/employment-contract` 스킬 내용 그대로 진행
- 2 → `/parttime-contract` 스킬 내용 그대로 진행
- 3 → `/flexible-contract` 스킬 내용 그대로 진행
- 4 → `/daily-worker-contract` 스킬 내용 그대로 진행

### 2) 개인 프리랜서·1인 사업자 선택 시

`/freelancer-contract` 스킬 내용 그대로 진행.

### 3) 외부 업체 선택 시

`/outsourcing-contract` 스킬 내용 그대로 진행.

### 4) 기존 직원 계약 변경 선택 시

```
[2단계] 어떤 변경인가요?

  1) 임금·근무조건 변경   → /contract-amendment
  2) 연봉 갱신            → /salary-renewal
```

- 1 → `/contract-amendment` 스킬 내용 그대로 진행
- 2 → `/salary-renewal` 스킬 내용 그대로 진행

## 규칙

- 선택지를 고르면 해당 스킬의 인터뷰를 이어서 바로 진행한다. 별도 명령어 입력 안내 없이 연속으로 진행.
- 모르겠다는 답변이 오면 상황을 설명받아 적합한 유형으로 안내한다.
- 전문용어는 쉬운 말로 풀어 설명한다.
