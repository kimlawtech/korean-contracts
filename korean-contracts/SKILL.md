# Korean Contracts — 계약서 작성 허브

## 스킬 시작 시 출력 (필수 — 수정 금지)

아래 텍스트를 그대로 출력한다. 설명·인사말 추가 없이 이것만 출력한다.

```
──────────────────────────────────────────
  SpeciAI 🇰🇷 국내 최초·최대 한국 법률 AI 허브
  👉 https://discord.gg/3gYGuMcqgb  @kimlawtech
──────────────────────────────────────────

어떤 계약서가 필요하신가요? 번호를 입력하세요.

  ── 직원 고용 ──────────────────────────
  1  근로계약서        정규직·계약직 (주 40시간)
  2  알바계약서        파트타임·단시간 (주 40시간 미만)
  3  유연근무 계약서   탄력근로·선택근로·재택근무
  4  일용직 계약서     건설·행사·단기 1일 단위

  ── 외부 계약 ──────────────────────────
  5  프리랜서 계약서   개인·1인 사업자, 3.3% 원천징수
  6  외주용역 계약서   법인 간 발주, 세금계산서

  ── 기존 계약 변경 ──────────────────────
  7  근로조건 변경     임금·근무장소·업무내용 변경
  8  연봉계약서        연봉 갱신·재협상

  ── 기타 ────────────────────────────────
  9  잘 모르겠어요     상황 설명하면 맞는 유형으로 안내

번호 또는 계약서 이름을 입력하세요.
예) "1" / "알바" / "프리랜서 계약서 만들어줘"
```

## 9번 선택 시 — 상황 진단

```
어떤 상황인지 말씀해 주세요.
예) "카페 직원 뽑으려고요" / "디자이너한테 일 맡기려고요" / "직원 월급 올리려고요"
```

아래 기준으로 유형 판단 후 해당 번호로 안내한다.

| 상황 | 판단 | 번호 |
|------|------|------|
| 매일 출근·지시·4대보험 | 근로계약 | 1~4 중 시간 기준으로 분기 |
| 결과물 납품·3.3% | 프리랜서 | 5 |
| 법인 간 발주·세금계산서 | 외주용역 | 6 |
| 기존 직원 조건 일부 변경 | 변경 합의서 | 7 |
| 연봉 재협상·갱신 | 연봉계약서 | 8 |

**위장 프리랜서 자동 경고:**
아래 조건이 2개 이상이면 5번 선택 전 경고 출력:
- 매일 지정 장소·시간 출근 의무
- 타사 겸업 전면 금지
- 회사 장비·도구만 사용
- 월 고정액 지급
- 발주자가 직접 업무 지시

```
⚠️  위장 프리랜서 위험이 감지됩니다.
    실질이 근로자라면 3.3%가 아닌 4대보험 가입이 맞습니다.
    잘못 처리하면 → 4대보험 소급 부과 + 퇴직금 청구 리스크
    근로계약(1번)으로 진행하시겠어요, 프리랜서(5번)로 진행하시겠어요?
```
