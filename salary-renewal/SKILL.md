## 핵심 법리 (연봉계약서 특유)

### 연봉계약서의 법적 성격

```
연봉계약서는 근로기준법 §17의 근로조건 명시 의무를 이행하는 문서다.
연봉계약서만으로 완전한 근로계약을 대체할 수 있으나,
기존 근로계약서가 있다면 연봉 부분만 갱신하는 방식도 가능하다.

필수 기재 사항 (§17):
1. 임금의 구성항목·계산방법·지급방법
2. 소정근로시간
3. 휴일·휴가
4. 취업 장소와 종사 업무
5. 근로 기간 (계약직인 경우)
```

### 고정OT 포괄임금제 적법 요건

```
포괄임금제가 유효하려면:
1. 연장근로가 상시·규칙적으로 발생할 것
2. 근로계약서에 고정OT 시간·금액 명시
3. 기본급 시급이 최저임금 이상일 것
4. 실제 연장근로가 고정OT 시간 초과 시 추가 지급 의무

주의: 단순히 "포괄임금"이라고 명시해도 최저임금 미달이면 무효
```

### 연봉 vs. 월급 표기

```
연봉제라도 근로기준법상 임금은 매월 지급해야 한다 (§43).
연봉 ÷ 12 = 월 지급액 (일반적 계산)
상여금·성과급은 별도 지급 계획 명시 권장
```

```

· 연봉 적용 기간 (예: 2026.01.01 ~ 2026.12.31)
```

### 3단계: 임금 구조 수집

```
연봉 구성 항목 (항목별로):
  - 기본급 (연간)
  - 식대 (월, 연)
  - 교통비 (월, 연)
  - 고정연장수당 (월, 연) — 고정OT 시
  - 기타 수당
  - 성과급·상여금 지급 기준 (있으면)

총 연봉액 = 위 항목 합계
월 지급액 = 총 연봉 ÷ 12
```

### 4단계: 최저임금 검증

```
기본급 기준 시급 환산:
  기본급 시급 = 기본급(연간) ÷ 12 ÷ (주소정근로시간 × 4.345)

2026년 최저임금 10,320원 미달 시 → 경고 출력, 생성 금지

고정OT 포함 시 추가 검증:
  소정근로 시급 = 기본급 시급
  → 기본급만으로도 최저임금 이상이어야 함 (연장수당 제외)
```

### 5단계: 소정근로시간·휴일·휴가 확인

```
· 주 소정근로시간 (기본값: 40시간)
· 주휴일
· 연차유급휴가 일수 (5인 이상: §60 기준, 1년차 15일)
· 5인 미만: 연차 의무 없으나 부여 여부 선택
```
